# College Lost & Found Android Application

An Android application developed using Kotlin, XML, Firebase, and Supabase to help college students report, search, and recover lost or found items.

## Technologies Used
- Kotlin
- XML
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Supabase Storage

## Key Features
- User registration and login
- Report lost and found items
- Search and view item details
- Upload item photos
- Manage personal reports
- Edit and delete reports
- Update item recovery status
- Send and approve contact requests
- Securely manage contact information
- User profile management

## Known Limitations
Photo access and upload permissions are being verified across multiple Firebase user accounts. Notifications currently depend on the app process being active.
